# Kayla Kautai — Portfolio

Personal site for Kayla Kautai, a software engineer specialising in Android. The landing page covers about, featured work, experience, and contact; `/projects` lists the full archive.

Live: [kkau201.github.io/portfolio](https://kkau201.github.io/portfolio)

Copy lives in `src/data/portfolioData.ts`. Update that file to change text, projects, awards, experience, and social links without editing components.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). Production builds use the GitHub Pages `basePath` `/portfolio`.

## Scripts

| Command | What it does |
| --- | --- |
| `npm start` / `npm run dev` | Next.js dev server |
| `npm run build` | Static export to `out/` |
| `npm run lint` | ESLint |
| `npm run deploy` | Build and publish `out/` to GitHub Pages |

## Stack

Next.js App Router, React, TypeScript, Tailwind CSS. Type is **Cal Sans** (headings) and **Be Vietnam Pro** (body).
