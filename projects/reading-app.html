Reading App

Personal Project | Native Android

A native Android reading companion with a home library shelf, Google Books search, and a yearly stamp card for books finished. Sign-in uses Firebase Auth. The shelf, profile, and reading sessions live in Firestore.

Timeline

2024 - Present

Role

Creator & Android Engineer

Stack

KotlinJetpack ComposeHiltFirebaseRetrofit
VIEW GITHUB

01/ The Challenge

I wanted to learn Firebase Auth and Firestore by shipping a real Android app, not a sample. The product goal was a shelf that feels like a bookcase: search Google Books, save a title, mark want to read, reading, or finished, log sittings, and watch a yearly stamp card fill in. That meant Compose UI, a restricted Books API key, and a signed-in cloud store for users, books, and sessions.

02/ Architecture

The dashboard is the shell. Screens talk to repositories. Auth, the shelf, and sessions live in Firebase. Search goes out to Google Books.

Dashboard and destinations

Four tabs sit in the dashboard: Home, Sessions, Search, and Profile. Compose Destinations owns the stack. Hilt ViewModels expose a UiState for loading, content, and errors.

Firebase for the shelf

Email sign-in uses Firebase Auth. Users, saved books, and reading sessions are Firestore collections, queried by the signed-in user. Saving, status, notes, ratings, and session logs all write through FireRepository.

Google Books search

Search and details come from the Google Books API through Retrofit. The key is restricted to this Android package. Each request sends the app package and signing certificate so Google will accept it.

A shelf, not a list

Home draws spines on a shelf, with the book you are reading pulled forward as a cover. Status chips filter the case. The currently reading title stays the tall one on the row.

Your shelf

Home is a bookcase. Filter by all, want to read, reading, or finished. The book in progress sits forward as a cover. The rest stand as spines.

Search

Type a title or author. Results come from Google Books, with a colour tick on the left so the list stays scannable.

Book detail

Cover, author, page count, and categories from Google Books. Once it is on your shelf you can change status, rate it, or remove it.

Profile

Name, bio, avatar, and tab colour. Counts for want to read, reading, and finished, plus what is on the nightstand now.

Stamp card

A yearly card on the profile. Each finished book stamps a mascot. Set how many books you want before the year ends.

Sessions

A sitting is pages plus an optional note. Log it against a book marked reading. The journal is stored in Firestore with the rest of the shelf.

Update a book

Move a title between want to read, reading, and finished. Add a star rating and a short note. Finished dates are optional.
